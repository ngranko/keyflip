# Menu is settings only: two slots, record trigger, login, quit

The extra’s menu does not run conversion. Opening it ends a typing session, so a Convert item would only be useful after a selection and fights the last-word rule. Pair-first is two slots (not a checklist). The trigger is recorded (default double-tap Option; double-tap Option/Control/Command using the mouse double-click interval; chords are modifier(s) + one key). Launch at login is an `SMAppService.mainApp` checkbox. Permissions are TCC prompts, not menu rows.
